# LocalReaderApp v0.1.0

LocalReaderApp is a Windows local-first reader for PDF, DOCX, and TXT files, with Vietnamese OCR and optional local VieNeu TTS.

## Included

- PDF text extraction and scanned-PDF OCR through `pypdfium2` and local Tesseract.
- DOCX XML extraction and client-side TXT/Markdown/plain-text reading.
- Local Vietnamese TTS integration; the model is downloaded on first use when enabled.
- Local server bound to `127.0.0.1`; cloud synchronization is disabled by default.
- MIT license, pinned CPU/GPU runtimes, third-party notices, security guidance, contribution rules, tests, and Windows CI.
- Source archive and SHA-256 checksum generated by the tag workflow.

## Install

1. Install Python 3.11 or 3.12 and Tesseract OCR with `vie.traineddata`.
2. Run `Setup Local Reader.bat`.
3. Run `Local Reader.bat` and open `http://127.0.0.1:8765`.

The first setup may download Python packages and the optional TTS model. No cloud account or API key is required for the core reader.

## Known limitations

- Windows is the supported platform; there is no standalone installer or packaged executable yet.
- OCR quality depends on Tesseract and its language data.
- The GPU lock resolves the pinned CUDA wheels, but GPU/TTS runtime verification requires a compatible NVIDIA machine.
- TTS model download, eSpeak NG availability, and generation speed depend on the user's machine.
- Adoption metrics and tester counts are intentionally not claimed until verified from real users.
